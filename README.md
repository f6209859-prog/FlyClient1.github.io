# Fly Client

Сайт клиента Fly Client для Minecraft 1.21.11.

## Структура

- `frontend/` — сайт, который можно разместить на GitHub Pages.
- `backend/` — API для регистрации, входа, ключей и админки.
- `database/` — SQL-схема.

## Важно

GitHub Pages не запускает Node.js backend. Поэтому frontend можно загрузить на GitHub Pages, а папку `backend` нужно запускать на сервере/хостинге Node.js.

## Запуск backend локально

```bash
cd backend
npm install
npm start
```

API будет на `http://localhost:3000`.

## Администратор

Администратора `noabot5` нужно создать отдельно на backend и назначить ему роль `admin`. Пароль не хранится в этом проекте.
